# DocInvoices

> Voice-powered invoicing for service businesses.

## Overview

DocInvoices is a Flutter application designed to help service professionals create estimates, invoices, and work records using a simple, voice-first workflow.

The goal is to reduce paperwork and allow mechanics, plumbers, electricians, HVAC technicians, landscapers, and other service businesses to create professional documentation quickly from the field.
